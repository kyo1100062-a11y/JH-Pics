## 1. 로그인 테스트

### TC-001: 정상 로그인

**테스트 목적**: 이메일/비밀번호로 정상적으로 로그인할 수 있는지 확인

**테스트 절차**:
1. 브라우저에서 `/login` 접속
2. 유효한 이메일 주소 입력 (예: `test@example.com`)
3. 유효한 비밀번호 입력
4. "로그인" 버튼 클릭

**기대 결과**:
- 로그인 성공
- 홈 페이지(`/`)로 자동 리다이렉트
- Header에 사용자 이메일 표시
- Header에 "로그아웃" 버튼 표시
- 로그인 버튼이 사라짐

**실패 시 점검 포인트**:
- [ ] Supabase 환경 변수 설정 확인 (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`)
- [ ] Supabase Dashboard에서 사용자 계정 존재 여부 확인
- [ ] 브라우저 콘솔에 에러 메시지 확인
- [ ] 네트워크 탭에서 API 호출 상태 확인 (401, 403 등)
- [ ] `auth.js`의 `signIn()` 함수 동작 확인

---

### TC-002: 잘못된 자격증명 로그인

**테스트 목적**: 잘못된 이메일/비밀번호 입력 시 적절한 에러 메시지가 표시되는지 확인

**테스트 절차**:
1. `/login` 접속
2. 존재하지 않는 이메일 입력 (예: `wrong@example.com`)
3. 임의의 비밀번호 입력
4. "로그인" 버튼 클릭

**기대 결과**:
- 로그인 실패
- 빨간색 에러 메시지 박스 표시
- 에러 메시지: "Invalid login credentials" 또는 "로그인에 실패했습니다."
- 로그인 페이지에 그대로 머무름
- 입력 필드는 유지됨

**실패 시 점검 포인트**:
- [ ] `Login.jsx`의 에러 처리 로직 확인
- [ ] `auth.js`의 `signIn()` 에러 반환 확인
- [ ] UI 에러 메시지 표시 로직 확인

## 3. Picture Set 생성 테스트

### TC-010: 새 Picture Set 생성

**테스트 목적**: 템플릿 선택 후 새 Picture Set을 정상적으로 생성할 수 있는지 확인

**테스트 절차**:
1. 로그인 상태에서 `/upload` 접속
2. 템플릿 선택 (예: "Type 4컷")
3. `/edit/new?type=4cut`로 이동
4. 상단 입력 영역에서:
   - 제목 입력 (예: "현장 확인 사진")
   - 사업명 선택 (드롭다운)
   - 보조사업자 입력 (예: "홍길동")
   - 담당자 입력 (예: "김철수")
5. "저장" 버튼 클릭

**기대 결과**:
- 저장 중 로딩 표시
- 저장 완료 알림 표시
- URL이 `/edit/{picture_set_id}`로 변경됨
- Supabase DB의 `picture_sets` 테이블에 레코드 생성됨
- `pages` 필드에 초기 빈 배열 저장됨

**실패 시 점검 포인트**:
- [ ] `EditPage.jsx`의 `handleSave()` 함수 확인
- [ ] 필수 필드 검증 로직 확인 (projectId, title)
- [ ] `pictureSets.js`의 `createPictureSet()` API 호출 확인
- [ ] Edge Function `/picture_sets` POST 엔드포인트 확인
- [ ] DB RLS 정책 확인

## 4. 이미지 업로드 테스트

### TC-012: 이미지 파일 업로드 (클릭)

**테스트 목적**: 이미지 슬롯 클릭으로 이미지를 정상적으로 업로드할 수 있는지 확인

**테스트 절차**:
1. `/edit/new?type=4cut` 접속
2. Picture Set 저장 (필수)
3. 빈 이미지 슬롯 클릭
4. 파일 선택 다이얼로그에서 이미지 파일 선택 (JPG, PNG 등)
5. 파일 선택

**기대 결과**:
- 이미지가 슬롯에 즉시 미리보기로 표시됨
- 이미지가 슬롯 크기에 맞게 `object-contain`으로 표시됨
- 이미지가 리사이징되어 base64로 저장됨
- Picture Set이 있으면 자동으로 Storage에 업로드됨
- 업로드 완료 후 Storage URL로 업데이트됨

**실패 시 점검 포인트**:
- [ ] `A4Canvas.jsx`의 `handleImageUpload()` 함수 확인
- [ ] `useImageEditor.js`의 `resizeImage()` 함수 확인
- [ ] 파일 타입 검증 로직 확인
- [ ] `upload.js`의 `uploadImage()` API 호출 확인
- [ ] Edge Function `/upload` POST 엔드포인트 확인
- [ ] Supabase Storage 버킷 설정 확인
